## Why

The language after the opening fence selects the syntax highlighting. Without it, a block of Rust or TOML renders as plain text, and the reader loses the colours that separate keys from values and code from comments. The language also tells the reader what they are looking at before they read it.

````markdown
```toml
[docs]
reference = ["docs/lints/**"]
```
````

An indented code block cannot name a language at all.

## How to fix

Name the language after the fence: `rust`, `toml`, `bash`, `json`. A shell session with `$` prompts and their output takes `console`; other output takes `text`. Turn an indented block into a fenced one.

## Configure

```toml
[lints.code-block-language]
level = "deny"
reason = "why this project wants it at this level"
```

Allow one finding in the code with `// spirit-level: allow(code-block-language) <reason>` ([waivers](../waivers.md)); the code works there too, as in `[lints.D0007]`.
