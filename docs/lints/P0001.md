## Parameters

| Name | Type | Default | Meaning |
|---|---|---|---|
| `files` | list of strings | `["AGENTS.md"]` | the agent files, relative to the root |
| `max-lines` | integer | `150` | lines a file may have |

## Why

An agent reads its rules file whole at the start of every session. Each line costs context in every session and dilutes the rules that matter. A short file is read and followed; a long one is skimmed.

```text
AGENTS.md: 212 lines (limit 150)
```

## How to fix

Keep the rules an agent must follow. Move explanations, layouts and how-tos into the book and link them.

## Configure

```toml
[lints.agent-file-lines]
level = "deny"
files = ["AGENTS.md"]
max-lines = 150
reason = "why this project wants it at this level"
```

Allow one finding in the code with `// spirit-level: allow(agent-file-lines) <reason>` ([waivers](../waivers.md)); the code works there too, as in `[lints.P0001]`.
