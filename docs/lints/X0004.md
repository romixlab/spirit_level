## Why

A yanked version was withdrawn by its authors, usually for a bug. `Cargo.lock` keeps it until it is updated.

## How to fix

`cargo update -p NAME` to a version that is not yanked.

## Configure

```toml
[lints.audit-yanked]
level = "deny"
reason = "why this project wants it at this level"
```

Allow one finding in the code with `// spirit-level: allow(audit-yanked) <reason>` ([waivers](../waivers.md)); the code works there too, as in `[lints.X0004]`.
