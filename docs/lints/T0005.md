## Why

`static mut` is global mutable state with no synchronisation at all: every access is `unsafe`, and since edition 2024 taking a reference to one is an error. There is always a better owner.

## How to fix

A counter or a flag is an atomic. Anything else gets one owner (see [static-interior-mutability](T0004.md)).

## Configure

```toml
[lints.static-mut]
level = "deny"
reason = "why this project wants it at this level"
```

Allow one finding in the code with `// spirit-level: allow(static-mut) <reason>` ([waivers](../waivers.md)); the code works there too, as in `[lints.T0005]`.
