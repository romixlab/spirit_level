## Parameters

| Name | Type | Default | Meaning |
|---|---|---|---|
| `patterns` | list of strings | `["**/.claude/settings.local.json", "**/CLAUDE.local.md", "**/.claude/projects/**", "**/.claude/todos/**", "**/.claude/**/*.jsonl", "**/*transcript*", "**/.aider.chat.history.md", "**/.aider.input.history", "**/.specstory/**"]` | globs of tracked files that are session files |

## Why

Agent transcripts and histories hold the whole session: private context, pasted secrets, paths of the author's machine. Per-person files (`.claude/settings.local.json`, `CLAUDE.local.md`) are meant to stay local. Neither belongs in the repo.

The rule lists the tracked files that match one of `patterns`.

## How to fix

`git rm --cached` the file, add the pattern to `.gitignore`, and check the history for secrets.

## Configure

```toml

reason = "why this project wants it at this level"
```

Allow one finding in the code with `// spirit-level: allow(agent-session-files) <reason>` ([waivers](../waivers.md)); the code works there too, as in `[lints.A0003]`.
