# D0004 page-headings { #D0004 }

**Rule:** A long page is divided into sections.

## Parameters

| Name | Type | Default | Meaning |
|---|---|---|---|
| `min-words` | integer | `400` | words of prose from which a page needs a section heading |
| `pages` | one of "all", "guide", "reference" | `"all"` | the kinds of page judged |

## Why

A long page without sections gives the reader no map: they cannot see what it covers, skip what they know, or find a part again. Section headings also become the page's table of contents and its link anchors.

The lint counts the prose words of a page. Above `min-words`, the page needs at least one heading below its title (`##` or deeper).

## How to fix

Divide the page into `##` sections, each named after what it answers. A page that covers several unrelated topics is often better as several pages.

## Configure

```toml
[lints.page-headings]
level = "deny"
min-words = 400
pages = "all"
reason = "why this project wants it at this level"
```

Allow one finding in the code with `// spirit-level: allow(page-headings) <reason>` ([waivers](../waivers.md)); the code works there too, as in `[lints.D0004]`.
