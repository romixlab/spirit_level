## Why

An unsound crate lets safe code cause undefined behaviour. RustSec marks such crates; cargo-audit reports them.

## How to fix

Update to a fixed version, or replace the crate.

## Configure

```toml
[lints.audit-unsound]
level = "deny"
reason = "why this project wants it at this level"
```

Allow one finding in the code with `// spirit-level: allow(audit-unsound) <reason>` ([waivers](../waivers.md)); the code works there too, as in `[lints.X0002]`.
