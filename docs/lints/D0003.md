| Name | Type | Default | Meaning |

| `pages` | one of "all", "guide", "reference" | `"guide"` | the kinds of page judged |

## Why

Headings are the page's table of contents. A reader scans them to find the part they need, and the navigation lists them. A short heading that names what the section answers is read at a glance. A heading written as a sentence is read like one, slowly.

```markdown
## Flashing over USB                                      <- a name

## How to flash the board over USB when the probe is busy  <- a sentence
```

## How to fix

Name the section in a few words. Move the rest of the sentence into the first paragraph under the heading.
