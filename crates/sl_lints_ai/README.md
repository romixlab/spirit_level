# sl_lints_ai

spirit_level's lints for code written with agents: stop-gap comments, commented-out code, lint tables that allow without a reason, near-duplicate functions and modules, features that enable nothing, and files committed by mistake (leftovers, agent settings with secrets or blanket permissions, session transcripts).

One analysis, `AI`. The tracked-file lints read `git ls-files`. Each lint's page is in `docs/<id>.md`; fixtures in `tests/fixtures/<id>/`.
